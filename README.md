# Reproducible Project (Course Assignment D1)

## Overview
This repository is a reproducible analysis project for the course assignment "Modern Tools & Workflows for Data Quality".
It demonstrates a transparent workflow with a clear project structure, version control (Git), and a runnable pipeline via `run.sh`.

## Project structure
- `data/` : input data (not modified)
- `code/` : analysis scripts
- `output/` : generated results (figures, logs)
- `run.sh` : runs the analysis pipeline

## Data
- File: `data/googletrend.csv`
- Source: Google Trends export (your own download)
- Note: The data contains no personal information.
